# SLP.Docs 앱 목적 및 핵심 흐름

## 1. 앱의 핵심 목적

**언어재활사/미술치료사를 위한 치료 일지 자동 생성 도구**

- 반복적이고 시간이 많이 소요되는 치료 일지 작성 과정을 자동화
- AI(Gemini)를 활용하여 전문적이고 일관된 치료 문서 생성
- 결제 내역 데이터를 기반으로 학생별 치료 이력 관리
- 다양한 형식(Word, HWPX, PDF)으로 문서 출력 지원

## 2. 주요 사용자

**언어재활사 및 미술치료사**
- 교육청 치료지원(마중물) 대상 학생들에게 치료 서비스 제공
- 월별/연별 치료 일지 작성 의무
- 전문적이고 표준화된 문서 작성 필요
- 시간 절약 및 업무 효율성 추구

## 3. 사용자가 가장 자주 하는 작업

### 3.1 데이터 입력 (1회성)
1. CSV/Excel 파일 업로드 (결제 내역)
2. 학생 정보 등록/수정

### 3.2 문서 생성 및 관리 (반복적)
1. 학생 선택
2. 연간계획서 확인/편집
3. 월별일지 확인/편집
4. 문서 다운로드 (Word, HWPX, PDF)
5. 인쇄

### 3.3 데이터 관리 (정기적)
1. 결제 내역 업데이트
2. 학생 정보 수정
3. 기존 문서 재생성

## 4. 가장 중요한 기능

### 4.1 핵심 기능 (Must Have)
1. **결제 데이터 파싱**: CSV/Excel 파일에서 학생 이름, 날짜, 금액 추출
2. **AI 문서 생성**: Gemini API를 활용한 연간계획서/월별일지 자동 작성
3. **문서 편집**: 생성된 문서의 수정 기능
4. **문서 출력**: Word, HWPX, PDF 형식 다운로드

### 4.2 부가 기능 (Should Have)
1. **학생 정보 관리**: CRUD 기능
2. **일괄 생성**: 여러 달 일지 동시 생성
3. **스케줄 검증**: 결제 날짜와 수업 요일 일치 확인
4. **인쇄 기능**: 브라우저 인쇄

### 4.3 선택 기능 (Nice to Have)
1. **데이터 내보내기**: 치료 이력 요약
2. **통계**: 월별/연별 치료 현황
3. **백업/복원**: 데이터 백업 기능

## 5. 사용자가 얻어야 하는 최종 결과

### 5.1 즉각적인 결과
- **연간계획서**: 학생별 연간 치료 목표 및 계획
- **월별일지**: 월별 치료 내용, 아동 반응, 결과 기록
- **인증된 문서**: 기관장 결재용 공식 문서

### 5.2 장기적인 결과
- **시간 절약**: 문서 작성 시간 70% 이상 단축
- **일관성**: 전문적이고 일관된 문서 품질
- **생산성**: 더 많은 학생에게 치료 서비스 집중

## 7. 목적 달성을 방해하는 부족한 부분

### 7.1 기능적 부족함
1. **인증 시스템 부재**: 여러 사용자가 같은 데이터에 접근
2. **데이터 검증 부족**: 잘못된 입력값 처리 미흡
3. **에러 복구 메커니즘 부재**: AI 생성 실패 시 대안 부족
4. **일괄 처리 제한**: 대량 데이터 처리 시 성능 문제

### 7.2 UX적 부족함
1. **초기 사용자 가이드 부재**: 첫 사용자가 흐름을 이해하기 어려움
2. **로딩 상태 피드백 부족**: AI 생성 시 긴 대기 시간
3. **모바일 대응 부족**: 태블릿/모바일에서 사용 어려움
4. **인쇄 품질**: 브라우저 인쇄로 인한 서식 불일치

### 7.3 기술적 부족함
1. **테스트 부재**: 코드 품질 검증 불가
2. **보안 취약점**: API 키 하드코딩, 인증 없음
3. **성능 문제**: 무거운 라이브러리, 최적화 부족
4. **유지보수성**: 중복 코드, 하드코딩

### 7.4 운영적 부족함
1. **모니터링 부재**: 에러 추적, 사용자 행동 분석 없음
2. **백업 전략 부재**: 데이터 손실 시 복구 불가
3. **문서화 부족**: 개발자/사용자 가이드 없음

## 8. 개선 방향 제안

### 8.1 즉시 개선 (1주일)
- 핵심 UX 개선 (빈 화면, 로딩 상태)
- 모바일 대응 강화
- 에러 메시지 개선

### 8.2 단기 개선 (1개월)
- 테스트 프레임워크 설정
- 타입 안전성 강화
- 코드 중복 제거

### 8.3 중기 개선 (3개월)
- 인증 시스템 구현
- 성능 최적화
- 모니터링 시스템 구축

### 8.4 장기 개선 (6개월)
- 고급 기능 추가 (통계, 백업)
- 다국어 지원
- 접근성 개선
