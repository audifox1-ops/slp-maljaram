# SLP.Docs 보안 가이드

## 아키텍처 보안 현황

### 현재 보안 수준
| 항목 | 상태 | 설명 |
|------|------|------|
| Firestore 규칙 | ✅ 강화됨 | 데이터 구조 검증, 필드 크기 제한 적용 |
| API 키 관리 | ⚠️ 개선 필요 | 클라이언트 번들에 노출 (Vite 환경 변수) |
| 인증 | ❌ 미구현 | 현재 인증 없이 접근 가능 |
| HTTPS | ✅ 적용됨 | Vercel 배포 시 자동 HTTPS |

### Firestore 보안 규칙
- `students`: 이름(50자), 생년월일, 학교(100자), 치료영역(50자) 필드 검증
- `payment_records`: 학생이름(50자), 거래일자, 치료영역 검증
- `annual_plans`: 최소 필드 구조 검증 (currentLevel, longTermGoals, monthlyGoals)
- `monthly_journals`: 최소 필드 구조 검증 (currentLevel, monthlyGoal, sessions, result)

### API 키 관리
현재 Gemini API 키는 Vite의 `import.meta.env.VITE_*`를 통해 클라이언트 번들에 포함됩니다.
이것은 Vite의 아키텍처적 한계이며, 완전한 해결을 위해서는 서버 측 프록시가 필요합니다.

**로컬 개발 환경**: `server.ts`의 `/api/generate` 엔드포인트를 통해 서버 측에서 API 키 관리
**프로덕션 환경**: Vercel Serverless Functions 또는 Edge Functions로 마이그레이션 권장

### .gitignore 보안
- `.env`, `.env.*`, `.env*.local` 파일은 git에서 제외
- `.env.example`만 커밋 (값 없음)
- Firebase 설정 파일(`firebase-applet-config.json`)에 API 키 포함 → gitignore 고려 필요
