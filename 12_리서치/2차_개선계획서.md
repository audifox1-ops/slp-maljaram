# SLP.Docs 2차 개선 계획서

## 개요
- **기간**: 2차 제품 완성도 개선
- **대상**: 기존 1차 개선 이후 남은 모든 개선 항목
- **목표**: 실제 문서 출력 품질 향상, 코드 품질 개선, UX 완성도 극대화

## 개선 항목 및 우선순위

### 1. 템플릿 설정 실제 반영 (Critical)
- **현재 상태**: `TemplateSettings`(기관명, 주소, 전화번호, 서체, 색상, 로고)가 localStorage에 저장되지만, 실제 문서 렌더링(`AnnualPlan`, `MonthlyJournal`)과 내보내기(`wordExportService`, `hwpxExportService`)에 반영되지 않음
- **개선 내용**:
  - `AnnualPlan`, `MonthlyJournal` 컴포넌트에 `templateSettings` props 추가
  - Word 내보내기 시 기관명/서체/색상 설정 반영
  - HWPX 내보내기 시 기관명 설정 반영
  - 문서 헤더에 기관 로고 표시 옵션
  - 문서 제목 커스터마이징 반영
- **기대 효과**: 실제 업무 환경에 맞는 맞춤형 문서 출력

### 2. 온보딩 일본어→한국어 수정 (Critical)
- **현재 상태**: `OnboardingModal.tsx`의 `getStepHint()` 함수가 일본어 텍스트 반환
- **개선 내용**: 모든 힌트를 한국어로 교체
- **기대 효과**: 사용자 이해도 향상

### 3. 워드 내보내기 중복 코드 제거 (Medium)
- **현재 상태**: `wordExportService.ts`에서 `renderMultiline`, `createBorder`, `borders`가 두 함수 내에 중복 정의
- **개선 내용**: 공통 유틸리티로 추출하여 코드 중복 제거
- **기대 효과**: 유지보수 용이성, 코드 품질

### 4. AI 응답 스키마 검증 (High)
- **현재 상태**: Gemini AI 응답을 `safeJsonParse`로 파싱한 후 타입 검증 없이 사용
- **개선 내용**: `AnnualPlanData`, `MonthlyJournalData` 구조에 대한 런타임 검증 함수 추가
- **기대 효과**: 잘못된 AI 응답으로 인한 런타임 에러 방지

### 5. 에러바운더리 개선 (Medium)
- **현재 상태**: `this.state.error?.message`를 사용자에게 직접 노출
- **개선 내용**: 사용자 친화적인 메시지로 대체, 개발자용 정보 별도 표시
- **기대 효과**: 사용자 경험 개선

### 6. 파일 업로드 크기 검증 (Medium)
- **현재 상태**: 파일 크기 제한 없음
- **개선 내용**: 10MB 제한 및 사용자 안내
- **기대 효과**: 메모리 부족 방지

### 7. CSS `animate-float` 클래스 추가 (Low)
- **현재 상태**: `AppFooter.tsx`에서 `animate-float` 클래스 사용하지만 CSS에 정의 없음
- **개선 내용**: 키프레임 애니메이션 추가
- **기대 효과**: 푸터 플로팅 효과 정상 동작

### 8. HelpTooltip 활용 (Low)
- **현재 상태**: `Tooltip.tsx`에서 `HelpTooltip` 컴포넌트 내보내기만 하고 미사용
- **개선 내용**: 주요 기능 영역에 도움말 툴팁 추가
- **기대 효과**: 사용자 안내 강화

### 9. 모바일 사이드바 토글 (Medium)
- **현재 상태**: 모바일에서 사이드바가 항상 열려 있음
- **개선 내용**: 모바일 화면에서 사이드바 토글 버튼 추가
- **기대 효과**: 모바일 사용성 개선

### 10. 인쇄 품질 강화 (Medium)
- **현재 상태**: 기본 인쇄 CSS만 존재
- **개선 내용**: 테이블 셀 너비 최적화, 페이지 나누기 개선
- **기대 효과**: 인쇄된 문서 품질 향상

## A/B 테스트 계획
